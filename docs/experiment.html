실험

W_history의 shrinkage parameter λ를 사이트의 실제 영화·배우 데이터로 검증. 가설 결과가 아니라 시간 순서를 보존한 다음 작품 예측 오차로 λ를 결정.

1. 실험 목적과 공식

현재 작품 이전까지의 Base Star Performance를 이용해 다음 작품의 Base Star Performance를 예측하고, λ별 예측 오차를 비교. λ는 전체 평균을 얼마나 강하게 신뢰할지를 조절하는 shrinkage strength.

B_im = W_market,m × W_role,im
B̂_history,im(λ) = [Σ B_ij + λ·μ_B,<t_m] / [n_im + λ]
W_history,im(λ) = √[ B̂_history,im(λ) / μ_B,<t_m ]
  • W_market,m = A_m / Total_Ym : 해당 영화 관객수 / 같은 연도 사이트 DB 내 영화 관객수 합
  • W_role,im = 1 / log₂(k_im + 1) : 출연진 순서에 따른 로그 할인 가중치
  • μ_B,<t_m : 현재 영화 개봉일보다 앞선 배우-영화 관측치의 Base SP 평균
  • n_im : 현재 영화보다 앞선 해당 배우의 유효 작품 수
  • λ : 전체 평균을 몇 개의 pseudo-observation만큼 신뢰할지 조절하는 값

3. λ 선택 및 데이터 기반 권장값

Primary criterion: 최소 MAE Tie-breaker: RMSE → 작은 λ

MAE/RMSE/Median AE는 읽기 쉽게 Base SP 오차에 10,000을 곱해 표시. 모든 λ에 동일한 상수를 곱하므로 최적 λ의 순위에는 영향을 주지 않음.

4. λ=1~10 예측 오차 비교

MAE와 RMSE가 낮을수록 과거 성과의 shrinkage estimate가 다음 작품의 Base SP에 더 가까웠다는 뜻. 권장 λ는 MAE 최솟값으로 결정.

5. 선택한 λ의 W_history 분포

W_history=1은 해당 시점의 사이트 평균 수준. 1보다 크면 평균 이상, 1보다 작으면 평균 이하의 과거 흥행 신뢰도를 의미. λ가 커질수록 값들이 1에 더 강하게 수축하는 것이 정상.

6. 과거 작품 수 구간별 예측 오차

λ는 과거 작품이 적은 배우의 과대·과소평가를 완화하기 위한 값. 특정 경력 구간 하나에서만 좋은 λ인지 구간 별로 확인.

7. λ 전체 결과표

λ MAE ×10,000 RMSE ×10,000 Median AE ×10,000 Spearman ρ 평균 W_history W_history SD 최저 MAE 대비 판정

8. λ

  1. 가설(H1/H2/H3), 사건 여부, 유튜브 여론은 λ 선택에 사용하지 않음.
  2. λ=1~10 중 MAE가 가장 낮은 값을 1차 선택.
  3. MAE가 수치적으로 동일한 경우 RMSE가 더 낮은 값을 선택.
  4. MAE와 RMSE까지 동일하면 더 단순한 정규화를 위해 작은 λ를 선택.
  5. 권장값이 1 또는 10이면 탐색 범위의 경계이므로 범위를 확장하기 전에는 최적값으로 확정하지 않도록.
  6. 최고값과 2위 값의 MAE 차이가 매우 작으면 “유일한 최적값”이라고 과장하지 않고, 주변 λ에서도 결과가 안정적인지 sensitivity analysis로 확인.
  7. 위 검증이 끝난 뒤에만 λ를 Star Power 공식의 default로 고정.
